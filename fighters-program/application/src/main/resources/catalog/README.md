# Card catalog (PROVISIONAL)

These five files are **placeholders** generated by the backend team so the game can be played end to end
before the official DSG catalogs are available (issue #40).

- Same schema as `catalogo-euroatlantica.json` on the Drive (`schemaVersion` 1, 16 cards per faction,
  8 Comune / 4 Rara / 3 Epica / 1 Leggendaria).
- Names, countries and stats are invented, except `EA16 Hana Kuroda`, which matches the known card.
- Codes `EA02`, `EA10`, `EA16` and `IP16` keep the names used in the balance document.

Replace each file with the official DSG version as soon as it is delivered: the startup import updates the
existing cards by code, so no migration is needed.
